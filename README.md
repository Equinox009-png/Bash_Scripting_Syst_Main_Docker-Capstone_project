# System Maintenance Suite (Docker)

Simple Dockerized suite of Bash scripts for system maintenance:
- `backup.sh` — create timestamped backups and keep last N
- `update_cleanup.sh` — apt update/upgrade and cleanup (Debian/Ubuntu)
- `log_monitor.sh` — scan logs for common error keywords
- `suite_menu.sh` — interactive menu to run scripts manually
- `entrypoint.sh` — container entrypoint; can start cron or drop to shell
